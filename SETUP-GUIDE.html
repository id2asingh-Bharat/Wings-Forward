✈️ Wings Forward — Setup Guide

Complete step-by-step instructions. No technical experience needed. Takes about 20 minutes.

0 What You'll Need All Free

  • ✅ A computer (Windows or Mac)
  • ✅ Internet connection
  • ✅ The 3 files I gave you (server.js, public/index.html, .env, package.json)
  • ✅ ~20 minutes

Cost: $0 to start. The API has a free tier (200 job searches/month). If you want to run it publicly online, hosting is ~$5–7/month — but first let's get it running on your computer.

1 Install Node.js on Your Computer Free · 5 min

Node.js is what runs the code behind the dashboard. Think of it like installing an app.

  1. Go to nodejs.org
  2. Click the big green button that says "LTS" (Recommended)
  3. Download and run the installer — just click Next → Next → Install
  4. When done, it will say "Node.js was successfully installed"
💡 To verify it worked: Press Windows key + R, type cmd, press Enter. Type node --version and press Enter. You should see something like v20.x.x

2 Get Your Free API Key Free · 5 min

This is what allows the dashboard to pull real live job listings. We use a service called RapidAPI + JSearch.

  1. Go to rapidapi.com/letscrape-6bRBa3QguO5/api/jsearch
  2. Click "Sign Up" (top right) — use your email, it's free
  3. After signing in, scroll down and click "Subscribe to Test" → choose the FREE plan (200 requests/month)
  4. Once subscribed, look on the right side of the page — you will see a box labeled "X-RapidAPI-Key" with a long string of letters and numbers
  5. Copy that entire key
💡 The free plan gives you 200 searches per month. That's plenty for personal use. If you want to run it for thousands of people, a paid plan is ~$10/month.

3 Set Up Your Project Folder 5 min

  1. Create a new folder on your Desktop called wings-forward
  2. Inside it, create another folder called public
  3. Copy the files like this:
    • server.js → goes in wings-forward/
    • package.json → goes in wings-forward/
    • .env → goes in wings-forward/
    • index.html → goes in wings-forward/public/
💡 The .env file may be hidden on your computer because it starts with a dot. Make sure hidden files are visible, or just create it manually in Notepad.

4 Add Your API Key to the .env File 2 min

Open the .env file in Notepad (right-click → Open with → Notepad). You'll see:

RAPIDAPI_KEY=PASTE_YOUR_KEY_HERE

Replace PASTE_YOUR_KEY_HERE with the key you copied in Step 2. Save the file.

✅ Example of what it should look like:
RAPIDAPI_KEY=abc123xyz789youractualkey...

5 Install & Run the Dashboard 3 min

Open your Command Prompt (Windows) or Terminal (Mac):

  • Windows: Press Windows key + R → type cmd → press Enter
  • Mac: Press Cmd + Space → type terminal → press Enter

Step A — Navigate to your folder:

cd Desktop/wings-forward

Step B — Install required packages (do this only once):

npm install

Wait for it to finish. You'll see a lot of text scroll by — that's normal.

Step C — Start the dashboard:

npm start

You'll see this message:

✈️ Wings Forward server running at http://localhost:3000

Step D — Open your browser and go to:

http://localhost:3000
🎉 The dashboard is live on your computer! Real job listings will load within a few seconds.

6 Put It Online So Anyone Can Access It ~$0–7/month

Right now it only runs on your computer. To share it with Spirit employees, you need to host it online. The easiest and cheapest option is Railway.app.

  1. Go to railway.app and sign up (free)
  2. Click "New Project" → "Deploy from GitHub"
  3. First, upload your folder to GitHub (free):
    • Go to github.com, sign up, click New Repository
    • Name it wings-forward, set to Public, click Create
    • Upload all your files by dragging them in
  4. Back in Railway, connect your GitHub account and select the wings-forward repo
  5. In Railway's settings, add your environment variable:
    Key: RAPIDAPI_KEY → Value: your API key
  6. Click Deploy — Railway gives you a free URL like wings-forward.railway.app
💡 Do you need a domain name? No! Railway gives you a free URL. If you want a custom one like wingsforward.org, that costs ~$12/year from Namecheap — but it's optional.

wings-forward/

└── public/
    └── index.html     ← The dashboard people see

❓ Troubleshooting

Dashboard shows "Could not load jobs"
→ Check your .env file — make sure the API key is correct with no extra spaces.

"npm: command not found"
→ Node.js didn't install correctly. Repeat Step 1 and restart your computer.

"Cannot find module"
→ You forgot to run npm install. Run it again.

Port 3000 already in use
→ Change PORT=3000 to PORT=3001 in your .env file and visit http://localhost:3001
